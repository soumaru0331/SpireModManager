# Spire Mod Manager

Slay the Spire 2（Steam 版）の MOD マネージャーです。作者: えす

## ダウンロード

右側の **Releases** から、いちばん新しい版の `SpireModManager_vX.X.X.zip` をダウンロードして、中の `SpireModManager.exe` を起動してください。
v1.6.0 からは、新しい版が出るとマネージャーの画面に「更新する」が出ます。押すだけで自動で入れ替わります。

## できること

- MOD のオン・オフ、前提 MOD の自動導入、エラー診断と解決方法の提示
- MOD の組み合わせ（プロファイル）を保存して、選んで起動
- 拾ってきた MOD（zip / 7z / rar）や Nexus Mods からのインストール、Workshop / Nexus の検索
- セーブの自動バックアップ、MOD 用セーブのキャラ解放
- MOD の日本語化（Google 翻訳）

A mod manager for Slay the Spire 2 (Steam). Download the latest zip from **Releases** and run `SpireModManager.exe`.
From v1.6.0 on, the app tells you when a new version is out and updates itself with one click.
