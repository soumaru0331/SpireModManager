# Tsumiki（ツミキ）

Slay the Spire 2（Steam 版）の MOD マネージャーです（旧名: Spire Mod Manager）。作者: えす

配布ページ: https://soumaru0331.github.io/Tsumiki/

## ダウンロード

[配布ページ](https://soumaru0331.github.io/Tsumiki/) か右側の **Releases** から `Tsumiki.exe` をダウンロードして起動してください。
v1.6.0 からは、新しいバージョンが出るとマネージャーの画面に「更新する」が出ます。押すだけで自動で入れ替わります。

## できること

- MOD のオン・オフ、前提 MOD の自動導入、エラー診断と解決方法の提示
- MOD の組み合わせ（プロファイル）を保存して、選んで起動
- 拾ってきた MOD（zip / 7z / rar）や Nexus Mods からのインストール、Workshop / Nexus の検索
- セーブの自動バックアップ、MOD 用セーブのキャラ解放
- MOD の日本語化（Google 翻訳）

---

A mod manager for Slay the Spire 2 (Steam), formerly Spire Mod Manager. Download `Tsumiki.exe` from https://soumaru0331.github.io/Tsumiki/ or **Releases** and run it.
From v1.6.0 on, the app tells you when a new version is out and updates itself with one click.
