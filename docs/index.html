What it does

MOD を入れて遊ぶときの「めんどう」と「なんで動かないの？」をまとめて片付けます。

Takes care of the chores — and the "why won't it work?" — of playing with mods.

On/off & auto requirements

Flip a switch. Missing requirements are installed from Workshop automatically.

よくある質問

FAQ

バニラ（MOD なし）のセーブは大丈夫？Is my vanilla (no-mod) save safe?

はい。ゲームは MOD 入りのセーブを別の場所に保存します。さらにこのツールは起動のたびにセーブ全体をバックアップし、いつでも戻せます。

Yes. The game keeps modded saves separately, and this tool backs up all saves before every launch so you can restore anytime.

ウイルス対策ソフトに止められたMy antivirus blocked it

個人が作った署名なしのソフトなので、止められることがあります。保存したフォルダを例外に追加してください。中身は GitHub の Releases で公開しています。

Unsigned personal apps can get flagged. Add the folder to your antivirus exceptions. Builds are published on GitHub Releases.

「Slay the Spire 2 が見つかりません」と出るIt says it can't find Slay the Spire 2

画面の「ゲームのフォルダを指定する」から、Slay the Spire 2 のフォルダを選んでください。それでもダメなら「診断情報をコピー」して作者に送ってください。

Use "Choose the game folder" and pick the Slay the Spire 2 folder. If that fails, use "Copy diagnostic info" and send it to the author.

消したいときは？How do I remove it?

exe を消すだけです。設定やバックアップは %LOCALAPPDATA%\SpireModManager にあります（いらなければ消してください）。

Just delete the exe. Settings and backups live in %LOCALAPPDATA%\SpireModManager (delete it if you don't need them).
